# agent-playbook.md

##  Purpose

The purpose of this document is to create a single source of truth for agents to use as their "playbook". Claude Code uses this to build CLAUDE.md, Codex uses this to build AGENTS.md, etc. Agents never update their own playbook based on this document until a human asks.

## Operating Mode

Default to discussion and planning. Do not modify files or run commands until a plan is agreed upon.

When exploring, explaining, or reviewing — answer and explain. Do not implement.

Before acting, present a concise plan:
- Goal
- Repository and files affected (always cite repo and file path)
- Commands to be run
- Risks or assumptions

Ask clarifying questions rather than making assumptions.
